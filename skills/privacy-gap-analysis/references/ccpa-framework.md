# CCPA/CPRA 差距分析框架

本文档定义在美国加州目标市场下，四个分析模块的差距检查清单、风险等级及对应法规依据。

适用法律：
- **CCPA**：California Consumer Privacy Act (Cal. Civ. Code § 1798.100 et seq.)
- **CPRA**：California Privacy Rights Act（2023 年 1 月 1 日起全面施行，对 CCPA 进行实质性修订）
- **CPRA 实施条例**：California Privacy Protection Agency（CPPA）2023 年最终规则

---

## 模块一：用户交互界面（UI Compliance）

### 高风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 缺少"Do Not Sell or Share My Personal Information"链接 | 网站首页及其他收集个人信息的页面未提供"Do Not Sell or Share My Personal Information"或等效链接，使加州消费者无法行使退出出售/共享权 | Cal. Civ. Code § 1798.135(a)(1) |
| 未响应全局隐私控制（GPC）信号 | 网站未识别或自动处理浏览器发出的 GPC（Global Privacy Control）信号，导致已启用 GPC 的加州用户的退出请求未被执行 | Cal. Civ. Code § 1798.135(b)；CPPA 条例 § 7025(a)(1) |
| 缺少敏感个人信息限制使用入口 | 网站收集并处理 CPRA 定义的敏感个人信息（如精确位置、种族、健康数据、金融账户、基因数据等），但未提供"Limit the Use of My Sensitive Personal Information"链接或等效机制 | Cal. Civ. Code § 1798.135(a)(2)；§ 1798.121 |
| 无任何隐私权利行使入口 | 网站未提供任何途径（如表单、邮箱、电话）供消费者提交 CCPA 数据主体权利请求（DSAR），包括知情权、删除权、更正权请求 | Cal. Civ. Code § 1798.130(a) |

### 中风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| "Do Not Sell or Share"链接不够显眼 | 上述链接虽然存在，但位置过于隐蔽（如仅在隐私政策内部文本中提及）或与周围内容混淆，普通用户难以识别和使用 | Cal. Civ. Code § 1798.135(a)（"清晰显眼"要求）；CPPA 条例 |
| 权利请求处理时限未告知用户 | 网站虽提供了 DSAR 提交渠道，但未告知用户请求将在 45 天内（可延期至 90 天）得到答复，未说明延期情况的处理方式 | Cal. Civ. Code § 1798.130(a)(2) |
| 未提供免费的权利请求渠道 | 网站对 DSAR 请求设置付费门槛或要求购买账户才能提交，对一般消费者构成障碍 | Cal. Civ. Code § 1798.130(a)(1)（免费服务要求） |
| 缺少验证身份的合理机制 | 网站接受 DSAR 请求但未说明如何验证申请人身份，或要求提供过多不必要信息进行验证 | CPPA 条例 § 7060-7063（验证程序要求） |

### 低风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 未提供双语（西班牙语）隐私权利信息 | 加州有大量西班牙语使用者，网站隐私权利说明仅有英文版本，缺少西班牙语版本 | CPPA 条例关于无障碍获取要求 |
| Cookie 退出入口与"Do Not Sell"入口未整合 | 网站分别设置了 Cookie 偏好中心和"Do Not Sell"链接，但两者未整合，导致用户需要在两处分别操作 | CCPA 最佳实践；CPPA 条例 |

## 模块二：隐私政策（Privacy Policy）

### 高风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 无隐私政策 | 网站（适用于年收入超过 2500 万美元、处理超过 10 万消费者数据、或超过 50% 收入来自出售个人信息的企业）未发布任何隐私政策 | Cal. Civ. Code § 1798.130(a)(5) |
| 未披露收集的个人信息类别 | 隐私政策未列出过去 12 个月内收集的个人信息类别（如标识符、商业信息、网络活动信息、推断数据等），或类别划分与 CPRA 定义不符 | Cal. Civ. Code § 1798.130(a)(5)(A) |
| 未说明收集个人信息的目的 | 隐私政策未说明收集各类个人信息的业务或商业目的 | Cal. Civ. Code § 1798.130(a)(5)(A) |
| 未披露出售或共享的个人信息类别 | 若企业出售或共享个人信息，隐私政策未列出出售/共享的信息类别及接收方类别 | Cal. Civ. Code § 1798.130(a)(5)(C) |
| 隐私政策超过 12 个月未更新 | 隐私政策超过 12 个月未经审查更新，可能与企业实际数据处理行为不一致 | Cal. Civ. Code § 1798.130(a)(5)(B) |
| 未说明消费者权利及行使方式 | 隐私政策未列明加州消费者依据 CCPA/CPRA 享有的全部权利，以及如何提交相应请求 | Cal. Civ. Code § 1798.130(a)(5)(A) |

### 中风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 未披露敏感个人信息的处理情况 | 企业收集和处理 CPRA 定义的敏感个人信息，但隐私政策未单独说明此类信息的收集目的和保留期限 | Cal. Civ. Code § 1798.121；CPPA 条例 |
| 数据保留期限说明缺失 | 隐私政策未说明各类个人信息的保留期限或确定保留期限的标准 | CPPA 条例 § 7102(c) |
| 未披露跨境数据传输情况 | 企业将加州消费者数据传输至美国以外地区，但隐私政策未就此告知消费者 | CCPA/CPRA 最佳实践；联邦贸易委员会（FTC）指南 |
| 未说明财务激励计划的材料条款 | 企业提供折扣、奖励或其他利益以换取消费者的数据，但隐私政策未说明此类财务激励计划的价值、计算方法及参与/退出方式 | Cal. Civ. Code § 1798.125 |
| 隐私政策信息不收集通知（Notice at Collection）缺失 | 在实际收集消费者个人信息时（如填写联系表单），未提供简要的即时告知，仅依赖用户主动查阅隐私政策 | Cal. Civ. Code § 1798.100(b)；CPPA 条例 § 7012 |

### 低风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 隐私政策未提供可替代联系方式 | 隐私政策仅提供一种 DSAR 提交方式（如仅邮件），但 CPRA 要求规模较大的企业应至少提供两种联系方式 | Cal. Civ. Code § 1798.130(a)(1) |
| 隐私政策中消费者权利描述不完整 | 隐私政策列出了部分消费者权利，但遗漏了 CPRA 新增的更正权（Right to Correct）或限制敏感信息使用权（Right to Limit） | Cal. Civ. Code § 1798.106（更正权）；§ 1798.121（限制权） |

## 模块三：用户协议（Terms of Service）

### 高风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 用户协议与隐私政策关于数据共享的条款相矛盾 | 用户协议中关于数据共享给第三方的条款，与隐私政策中出售/共享声明存在实质性冲突，可能误导消费者对其数据如何被使用的理解 | Cal. Civ. Code § 1798.100(a)（不得歧视原则）；FTC 第 5 条 |

### 中风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 用户协议使用宽泛授权条款变相规避退出权 | 用户协议要求用户同意将数据用于"任何合法商业目的"等宽泛表述，并将继续使用服务视为对数据出售的"同意"，实质上影响消费者退出权的行使 | Cal. Civ. Code § 1798.120(a)（退出权不得以合同方式剥夺） |
| 未成年人数据处理条款缺失 | 用户协议未说明对 16 岁以下未成年人数据的处理方式，也未说明出售未成年人数据的选择加入（opt-in）要求 | Cal. Civ. Code § 1798.120(c)（16 岁以下需选择加入） |

### 低风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 用户协议未交叉引用隐私政策 | 用户协议未包含隐私政策的链接或引用，用户难以将两个文件关联理解 | CCPA 最佳实践 |

## 模块四：Cookie 与追踪技术（Cookie & Tracking）

### 高风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| 未识别和响应 GPC 信号 | 网站未对 Global Privacy Control（GPC）浏览器信号作出自动响应，对已启用 GPC 的用户继续进行数据共享或出售 | Cal. Civ. Code § 1798.135(b)；CPPA 条例 § 7025(a)(1) |
| 第三方广告追踪器构成"出售或共享"但未披露 | 网站使用 Google Ads、Meta Pixel、TikTok Pixel 等第三方广告追踪技术，将消费者数据传输给第三方平台用于定向广告，构成 CPRA 下的"共享"，但未在隐私政策中作为"出售或共享"予以披露，也未提供退出选项 | Cal. Civ. Code § 1798.140(ah)（"共享"定义包含跨情境行为广告）；§ 1798.120 |
| Cookie 使用与隐私政策披露不符 | 技术检测发现的第三方 Cookie 类型或数量超出隐私政策中披露的范围，存在未披露的数据共享行为 | Cal. Civ. Code § 1798.130(a)(5)（披露义务） |

### 中风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| Cookie 同意偏好中心未整合 CCPA 退出选项 | 网站设置了 Cookie 管理界面，但该界面与"Do Not Sell or Share"退出机制未整合，用户需要分别操作两个独立系统 | CPPA 条例（用户体验合理性要求） |
| 未说明营销 Cookie 对应的"出售或共享"性质 | 网站使用了营销 Cookie，但 Cookie 政策仅将其描述为"营销/广告"用途，未明确告知这构成 CPRA 下的"共享"并说明消费者的退出权利 | Cal. Civ. Code § 1798.140(ah)；§ 1798.135 |
| 服务提供商与第三方的 Cookie 区分不清晰 | Cookie 政策未区分由"服务提供商"（Service Provider，签有数据处理协议且仅为业务目的处理数据）和"第三方"（Third Party，独立控制数据）设置的 Cookie，导致消费者无法判断哪些 Cookie 属于"出售或共享"范畴 | Cal. Civ. Code § 1798.140（服务提供商 vs. 第三方定义）；CPPA 条例 |

### 低风险差距

| 差距名称 | 差距描述 | 法规依据 |
|---------|---------|---------|
| Cookie 政策缺少按需更新机制 | Cookie 政策未说明如何定期审查和更新第三方 Cookie 列表，可能导致实际使用的 Cookie 与已披露信息不一致 | Cal. Civ. Code § 1798.130(a)(5)(B) |

## 法规依据原文（参考）

以下为核心条款的关键内容摘要：

### CCPA/CPRA 关键条款

**Cal. Civ. Code § 1798.100(a) — 知情权**
> 消费者有权知晓企业收集的个人信息的类别和具体内容。

**Cal. Civ. Code § 1798.105 — 删除权**
> 消费者有权要求收集其个人信息的企业删除该消费者向企业提供的个人信息……

**Cal. Civ. Code § 1798.106 — 更正权（CPRA 新增）**
> 消费者有权要求收集其个人信息的企业更正企业持有的关于该消费者的不准确个人信息……

**Cal. Civ. Code § 1798.120(a) — 退出出售/共享权**
> 消费者有权随时指示出售其个人信息或为跨情境行为广告目的共享其个人信息的企业停止出售或共享该消费者的个人信息……

**Cal. Civ. Code § 1798.121 — 限制敏感个人信息使用权（CPRA 新增）**
> 消费者有权指示收集敏感个人信息的企业将该信息的使用和披露限制于提供服务或商品所必要的目的……

**Cal. Civ. Code § 1798.130(a)(5) — 隐私政策要求**
> 每年至少一次，披露：(A) 企业在过去 12 个月内收集的个人信息类别……(B) 更新的披露……(C) 出售或共享的个人信息类别……

**Cal. Civ. Code § 1798.135(a) — 退出权的通知**
> (1) 在企业网站的互联网主页上提供清晰显眼的"Do Not Sell or Share My Personal Information"链接……
> (2) 若企业收集敏感个人信息，还需提供"Limit the Use of My Sensitive Personal Information"链接……

**Cal. Civ. Code § 1798.135(b) — GPC 信号**
> 企业应将全局隐私控制视为消费者拒绝出售其个人信息或共享其个人信息的有效选择……

**Cal. Civ. Code § 1798.140(ah) — "共享"定义**
> "共享"指企业出于跨情境行为广告目的，将消费者的个人信息披露、出售、出租、发布、转移、传播、发送……给另一个企业或第三方……无论是否提供金钱报酬。

### CPPA 条例关键规定

**§ 7012 — 收集通知（Notice at Collection）**
> 企业在或在收集消费者个人信息之前……应向消费者提供收集通知，内容包括：所收集的个人信息类别；每类信息的处理目的；隐私政策或通知的链接……

**§ 7025(a)(1) — GPC 合规**
> 企业应将浏览器或设备发出的 GPC 信号视为消费者就该设备或浏览器退出出售和共享的有效选择，并应及时响应该信号。
